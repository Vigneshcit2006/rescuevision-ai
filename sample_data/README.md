# Sample / Demo Data

RescueVision AI's demo mode does **not** ship any video files in this
repository. Instead, `backend/app/vision/video_source.py::SyntheticFrameSource`
programmatically renders each demo scenario, frame by frame, using OpenCV 5
drawing primitives (`cv2.rectangle`, `cv2.circle`, `cv2.putText`) plus a small
amount of seeded per-frame noise.

## Why synthetic, not real footage

1. **No copyright/licensing risk.** Every pixel is generated by code in this
   repository; nothing is downloaded, scraped, or sourced from a
   third party.
2. **Fully deterministic and reproducible.** `SyntheticFrameSource(scenario,
   num_frames, fps)` produces the exact same frame sequence every run for a
   given scenario name and frame count (the only randomness is a
   frame-index-seeded noise pattern, so it is reproducible too — see the
   `np.random.default_rng(seed=i)` call in `_render`). A judge re-running the
   demo gets the same escalation timeline every time.
3. **No dependency on a webcam or uploaded file during judging.** The demo
   works identically on any machine with no camera attached.

## The four scenarios (`POST /api/demo/start {"scenario": ...}`)

| scenario            | what is rendered                                                                 | expected outcome                        |
|---------------------|-----------------------------------------------------------------------------------|------------------------------------------|
| `normal`             | A static room with unmoving furniture; no incident signal is ever introduced.     | Stays in `none` state; no incident.       |
| `fire_smoke`         | A flame (orange/red HSV-colored disc) grows from ~frame 30, with a grey smoke plume rising from ~frame 50. | Escalates none → possible → confirmed.  |
| `person_down`        | A standing silhouette (tall rectangle) falls to a horizontal position between frames ~40-55 and stays down. | Escalates and always requires human approval per policy. |
| `route_obstruction`  | A vehicle-like block grows across a marked emergency-route rectangle from ~frame 25. | Escalates once the occluded-area ratio persists. |

## Using real video instead

`POST /api/analyze` (multipart upload) and `VideoSource` in
`backend/app/vision/video_source.py` support any real video file or a live
webcam (`VideoSource(0)`) via `cv2.VideoCapture` — the synthetic generator is
only used for the deterministic `/api/demo/start` judge-facing flow. If you
have your own (properly licensed / consented) footage of a fire, a person
falling, or a blocked route, you can upload it through `/api/analyze` to see
the same pipeline run on real frames. No such footage is included in — or
required by — this repository.
