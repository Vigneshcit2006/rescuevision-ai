## Why this is a small benchmark, on purpose

There is no real-world video dataset in this project — all detection-quality
numbers come from 4 deterministic synthetic clips
(`sample_data/README.md`), and all timing numbers come from a single run on
a single machine. Both are stated plainly rather than dressed up: see the
report's limitations section for exactly what would need to change (a real
labeled dataset, repeated multi-machine timing runs, a live AWS deployment)
to turn this into a defensible production benchmark.

## Reproducing these numbers yourself

```bash
python evaluation/run_evaluation.py
```

Takes roughly 2 minutes and writes a fresh timestamped JSON to
`evaluation/results/` plus an overwritten `evaluation/results/latest.json`.
No AWS credentials or network access required.
